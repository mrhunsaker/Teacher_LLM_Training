# Participant Lesson Handouts

Use the editable Word handouts listed below as the participant working materials for the ten-session course. This page is a guide and download index; the handout content is maintained in the DOCX files, not reproduced as Markdown on this page.

Choose one role-relevant case from the [unified Buendía-family case collection](multidisciplinary-case-studies.md) and carry it through the activities. Adapt each task to your professional role and scope of practice.

## Source files and maintenance

The DOCX files are the participant-facing materials. Their Markdown source files are maintained in the repository for course-authoring and regeneration; participants do not need to use the Markdown source. See the [handout index](https://github.com/mrhunsaker/Teacher_LLM_Training/blob/main/my-book/handouts/README.md) for the file inventory.

## Privacy and professional boundaries

Use fictional or synthetic information for course practice. For real work, use only specifically district-approved tools and data workflows. Do not enter identifiable student or staff information into an unapproved system. The handouts support professional planning and reflection; they do not delegate diagnosis, evaluation, eligibility, placement, services, IEP decisions, or other reserved professional judgments to an LLM.
