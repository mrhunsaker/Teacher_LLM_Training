# Fictional Student Case: Aureliano Buendia — Access, Independence, and Dual-Media Learning

> **Training case only:** Aureliano Buendia is fictional. All observations, names, and sample values in this chapter are invented for professional-learning practice. Do not copy this profile into an actual student record.

## Case snapshot

Aureliano Buendia is a student with **ocular albinism and photophobia**. With corrective lenses, her measured visual acuity is **20/175**. She wears her glasses and requires a **brimmed hat** to reduce the impact of overhead lighting. She is highly sensitive to glare. Her academic performance is solidly in the **B range**; academic achievement is generally good.

Aureliano Buendia receives orientation and mobility (O&M) instruction. She is learning braille as a second literacy medium so that she can become a **dual-media reader**. For visual access, she is learning to use **Windows Magnifier** (with ZoomText as a possible alternative if the team determines that its features are needed and funding is available). She also uses an **iPad in class**.

The instructional question is not “How do we fix Aureliano Buendia's grades?” Her grades are good. The question is: **How can the team make access efficient, comfortable, independent, and sustainable across environments, materials, and tasks—while developing literacy and technology options for the future?**

## Known information and information still to collect

| Known from the fictional case | Not yet established; do not assume |
|---|---|
| Ocular albinism and photophobia | Specific ocular findings beyond the diagnosis provided |
| Corrected visual acuity: 20/175 | Functional vision performance at different distances, lighting levels, and task types |
| Glasses and brimmed hat are required supports | Whether additional filters, monitor settings, or seating changes are beneficial |
| High sensitivity to glare | Exact sources, locations, and times when glare is most disruptive |
| Solid B-range academic performance | Whether current grades require extra time, effort, adult assistance, or reduced access to some materials |
| O&M services are in place | Current O&M objectives, travel performance, and environmental barriers |
| Learning braille as a dual-media reader | Current braille readiness, tactile skills, reading fluency, and contexts in which braille is most useful |
| Learning Windows Magnifier; ZoomText is an alternative | Current proficiency, preferred settings, task efficiency, and whether built-in magnification meets access needs |
| Uses an iPad in class | Which apps, accessibility settings, workflows, and file formats are currently effective |

**Instructional safeguard:** Do not infer functional vision needs or select a primary literacy medium from acuity alone. Use the student's learning media assessment, functional vision information, learning media plan, clinical guidance where appropriate, observations across settings, and student/family input. The LLM can help organize questions and options; it cannot perform an assessment or make the team's decisions.

## The collaborative design cycle

The course uses a repeated **Plan → Refine → Build → Refine** cycle. It is not “write one prompt and accept the answer.” The TVI leads the work, brings context and evidence, evaluates the model's output, and decides what to test next.

1. **Plan — define the instructional problem.** Identify the ECC domain, real-world task, setting, access barrier, student strength, and evidence already available. Separate known facts from questions.
2. **Refine — interrogate and narrow the plan.** Ask the LLM to identify missing information, competing explanations, risks, and measurable options. Correct assumptions and add only verified context. The teacher decides the target.
3. **Build — create a small, testable tool or instructional component.** Examples include an observation sheet, a student practice sequence, a Windows Magnifier checklist, a glare/access audit, or a data tracker. Build only what the team has agreed to test.
4. **Refine — test, review, and revise.** Use the tool in the actual setting, collect data, inspect usability with Aureliano Buendia and relevant staff, and ask the LLM to help summarize patterns. Revise the tool or plan based on evidence. Keep a record of what changed and why.

At every stage, the teacher can stop, reject, or redirect the model. The model should not silently move to the next stage.

## A worked Plan → Refine → Build → Refine example

### 1. Plan: identify a bounded access problem

A useful starting focus is **access to digital classroom materials using Windows Magnifier**. This is a practical skill within assistive technology and can be coordinated with classroom routines. It does not imply that magnification is the only appropriate medium or that braille instruction should be reduced.

The teacher first defines the task in observable terms. For example:

- Aureliano Buendia opens an assigned digital document on a Windows device.
- She turns on or accesses Windows Magnifier using the agreed method.
- She adjusts magnification and, when needed, the view so that the relevant content is visible.
- She navigates to the assigned section and completes the classroom task.
- She uses her glasses and brimmed hat and follows agreed glare-reduction arrangements.
- The teacher records the level of prompting, time or effort when relevant, and any access barriers.

This is a **candidate task analysis**, not a claim that Aureliano Buendia currently performs or struggles with any of these steps. The TVI should confirm the actual workflow with Aureliano Buendia and classroom staff.

**Prompt for the Plan stage**

> Act as a collaborative planning assistant for a teacher of students with visual impairments. Use only the fictional case facts in this chapter. We are considering a short instructional cycle for Aureliano Buendia's use of Windows Magnifier to access classroom documents. Do not write a goal or lesson yet.  
>   
> Return: (1) the instructional problem stated neutrally in two sentences; (2) known facts; (3) information we need to observe before selecting a target; and (4) up to five possible observable task components. Mark every unknown as “not yet observed.” Do not infer a deficit from Aureliano Buendia's B-range grades or her visual acuity. Stop after these four sections.

### 2. Refine: challenge the first plan

The teacher reviews the response and asks:

- Does the proposed task match the device and document formats Aureliano Buendia actually uses?
- Is the workflow accessible with the school's Windows configuration?
- Does it account for glare, display placement, contrast, font size, and comfortable viewing distance without prescribing unassessed settings?
- Does it distinguish operating Magnifier from using it efficiently to complete a meaningful task?
- Does it preserve braille learning and the iPad workflow as parallel access options?
- Are prompts, accommodations, and independence defined clearly enough to measure?

**Prompt for the Refine stage**

> Review the proposed task components as a critical colleague. Identify ambiguities, hidden assumptions, and steps that may not be necessary for Aureliano Buendia. Separate questions that require observation from questions the teacher can answer from existing records. Do not add new case facts. Suggest a leaner task analysis with no more than six steps. Do not write a goal, lesson, or data sheet.

The teacher edits the task analysis. For example, if Aureliano Buendia's device is already configured and she only needs to select a suitable magnification level and navigate a document, the team should not measure unnecessary setup steps. Conversely, if opening a file, changing the view, or returning to the relevant location is part of the real classroom barrier, those steps may belong in the analysis.

### 3. Build: create one small classroom-ready artifact

After the task is confirmed, ask the LLM to build a tool that supports observation—not a complete IEP or a predetermined intervention.

**Prompt for the Build stage**

> Using only the teacher-approved task analysis below, create a one-page observation form for a TVI to use during three or more separate practice opportunities. Include: date and setting; task/material; lighting and glare notes; device and access method; each task step; independent, verbal prompt, gestural prompt, or physical assistance; whether the task was completed; student feedback about comfort and efficiency; and a notes field. Keep observed performance separate from interpretation. Do not invent baseline scores, goal criteria, or service recommendations.  
>   
> [Paste the teacher-approved task analysis.]  
>   
> Output only the form.

The TVI then checks the form for practical use, accessible formatting, and alignment with district documentation practices. The classroom teacher may need a shorter companion checklist for naturally occurring opportunities. The iPad, braille, and print workflows should be documented separately when the team is comparing access routes; do not collapse different tools or media into one accuracy score.

### 4. Refine: use actual observations to revise the tool

After data collection, the TVI can provide a de-identified summary—not names, dates of birth, school identifiers, or raw records that could identify Aureliano Buendia—and ask the LLM to help inspect the quality of the data.

**Prompt for the Refine stage**

> I am reviewing a fictional, de-identified observation summary for a student learning Windows Magnifier. Do not decide whether the student has mastered the skill. First check whether the observations are sufficient to interpret performance. Identify missing fields, inconsistent prompt definitions, changes in task difficulty, and possible environmental influences such as glare or lighting. Then summarize only patterns directly supported by the data and list questions for the TVI and classroom teacher. Do not invent values or recommend reducing braille, O&M, or other services.  
>   
> [Paste the de-identified observation summary.]

The teacher may discover that the form needs a separate field for document type, that staff are using “prompt” inconsistently, or that glare conditions differ between sessions. The next iteration should address the identified problem. The team may repeat the cycle with a revised form or select a different instructional target.

## Potential ECC strands for a coordinated case study

These are planning avenues, not predetermined deficits or goals.

### Assistive technology

- Develop functional use of Windows Magnifier for digital classroom materials.
- Compare built-in magnification with ZoomText only when an observed access need justifies evaluating the additional software.
- Document how Aureliano Buendia uses her iPad and whether workflows transfer across apps, file types, and classroom tasks.
- Teach Aureliano Buendia to describe and request the display, contrast, magnification, and document-access conditions that work for her.

### Sensory efficiency and visual access

- Observe the effect of overhead lighting, reflected glare, screen glare, and task lighting in actual learning environments.
- Confirm consistent access to glasses and the brimmed hat.
- Collaborate with the student, family, classroom staff, and relevant professionals on environmental adjustments.
- Record the conditions under which visual access is comfortable and efficient; do not assume one setting works in every room.

### Compensatory access and dual-media literacy

- Support braille development as an additional literacy medium.
- Coordinate print, digital magnification, and braille opportunities based on the learning media plan and task demands.
- Avoid framing braille as a response to academic failure. Aureliano Buendia's good grades do not remove the value of developing a flexible second medium.
- Track reading access, stamina, efficiency, and student preference separately for each medium.

### Orientation and mobility

- Coordinate classroom and campus access observations with the O&M specialist.
- Consider how lighting, glare, transitions, and visual information affect travel in different environments.
- Keep O&M assessment, instruction, and decisions under the qualified O&M professional's direction. Do not ask an LLM to infer travel safety or prescribe routes.

### Self-determination and self-advocacy

- Support Aureliano Buendia in explaining her access needs, requesting agreed accommodations, and evaluating whether tools are working.
- Include student feedback about comfort, fatigue, efficiency, and preference.
- Teach the student to identify when a different medium or tool is more effective for a particular task.

## Candidate data questions for the team

Use these as observation questions before drafting any IEP goal:

1. Under what lighting and glare conditions does Aureliano Buendia report comfortable and effective visual access?
2. Which classroom materials are accessible through print, digital magnification, braille, or a combination?
3. What steps can Aureliano Buendia complete independently when using Windows Magnifier for a real classroom task?
4. Which Magnifier settings and navigation strategies does she select and use consistently?
5. How does her access differ across Windows devices, iPad applications, document formats, and classroom environments?
6. What braille skills are emerging, and in which instructional contexts is braille currently being used?
7. What does the O&M specialist observe about access and travel in relevant environments?
8. How does Aureliano Buendia describe the effort, comfort, and efficiency of each access method?

Do not answer these questions by guessing from the case profile. Collect observations and invite Aureliano Buendia's perspective.

## Case-study deliverables for the professional-learning team

By the end of this case, participants should have collaboratively produced:

1. A one-page known-facts / unknowns map.
2. A teacher-approved task analysis for one ECC skill.
3. A TVI observation form and a concise classroom-teacher companion form.
4. A plan for observing access conditions and student-reported comfort.
5. A de-identified data summary with prompt levels and comparable opportunities.
6. A revision log showing what the team changed after reviewing evidence.
7. A list of questions that require the IEP team, learning media assessment, or O&M professional—not an LLM—to resolve.

## Reflection: evidence over automation

- Where did the LLM help the teacher think more clearly?
- Which model suggestions did the teacher reject, and why?
- What did Aureliano Buendia's own feedback change in the plan?
- Did the team preserve braille, magnification, iPad access, and O&M as distinct but coordinated strands?
- What evidence would justify revising the instructional approach?
- What must remain a professional or team decision?

**The measure of success is not how much content the LLM generates. It is whether the teacher and student use an iterative process to create a more accessible, measurable, and useful learning experience.**
