# Module 3: Building Aligned Data-Collection Tools

## Learning targets

- Define the target skill as observable steps or opportunities.
- Create a TVI data sheet and a classroom-teacher data sheet that measure the same skill.
- Record prompts, conditions, and generalization so that scores are interpretable.

## Start with an operational definition

Before creating a worksheet, answer:

1. What exactly counts as one opportunity?
2. What counts as correct?
3. What counts as incorrect, no response, or not applicable?
4. Which prompts are allowed, and how are they coded?
5. What accommodations or access technology must be available?
6. What conditions must be held constant?
7. Which skills should be checked across settings or people?

Do not use a percentage if the denominator is unclear. For task analysis, score each step consistently. For frequency, record count and observation duration. For latency or fluency, record time using a defined start and stop.

## Shared data dictionary

| Field | Definition |
|---|---|
| Learner code | Neutral, non-identifying label |
| Date/session | Date or session number; avoid unnecessary identifying details |
| Observer | Staff role or initials per district practice |
| Setting/activity | General setting description |
| Opportunities | Number of valid chances to demonstrate the skill |
| Independent correct | Correct responses with no prompt beyond the defined natural cue |
| Prompted correct | Correct only after a coded prompt |
| Incorrect/no response | Not completed correctly within the defined opportunity |
| Prompt code | I = independent; V = verbal; G = gestural; M = model; P = physical; NA = not applicable |
| Access conditions | Device, magnification, contrast, lighting, tactile materials, or other relevant supports |
| Notes | Brief factual context; avoid subjective labels |

Adapt prompt codes to the student's plan and district terminology. Physical prompting may be inappropriate for some skills; never use a code set without team agreement.

## Quick scoring rules

- Independent accuracy = independent correct ÷ valid opportunities × 100.
- Total correct including prompted responses may be calculated separately, but must not be mislabeled independent accuracy.
- If there are zero valid opportunities, record “no data”; do not calculate 0%.
- If the conditions differ materially from the goal, flag the session rather than silently combining it.
- Record the number of opportunities as well as the percentage. 10/11 and 1/1 are not equally stable estimates.
- For skills with safety implications, follow the specific safety protocol; do not treat a percentage threshold as permission to reduce supervision.

## Prompt to create a tailored worksheet

> Create two one-page data collection forms for the following synthetic ECC skill and operational definition: [insert]. One form is for a teacher of students with visual impairments during direct instruction; the other is for a classroom teacher during naturally occurring routines. Both forms must measure the same observable behavior and use the same definition of opportunity, correct response, prompt levels, and access conditions. Include date, setting/activity, opportunities, independent correct, prompted correct, incorrect/no response, and factual notes. Do not invent student information. Use accessible, uncluttered formatting and plain labels. Output the two tables only.

## Accessibility considerations

- Use descriptive column headings, not color alone.
- Avoid merged cells in data-entry tables.
- Freeze the header row in Excel.
- Use high contrast and readable font size.
- Ensure the form works with screen readers and keyboard navigation.
- Provide a printable version with sufficient writing space.
- Ask the student which format is usable; do not assume a single format based on a diagnostic label.

## Quality check

Can two different adults use the forms and score the same opportunity consistently? If not, clarify the operational definition before collecting more data.
