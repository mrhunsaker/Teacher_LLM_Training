# Additional Fictional Student Practice Cases

These profiles are invented for professional learning. They are not templates for real students. Each profile deliberately leaves important information unknown so participants practice asking questions rather than filling gaps.

## Case A: Dual-media literacy

A fictional middle-school learner uses print and braille in different learning activities and reports that some classroom materials take longer to access than peers' materials.

**Known:** The learner uses both print and braille; access time varies by activity according to the learner.

**Unknown:** Reading rates; preferred medium by task; braille proficiency; fatigue; material availability; layout, lighting, and device factors; observations across classes.

**Practice task:** Plan a structured comparison of access workflows for one recurring classroom activity. Do not assume one medium should replace the other.

**Review:** Include student voice and relevant learning media assessment. Do not infer media decisions from diagnosis or one task.

## Case B: Digital access and assistive technology

A fictional learner uses a tablet for some school tasks and is beginning to use magnification on a Windows computer. Staff report that familiar activities are completed more efficiently than new documents.

**Known:** Tablet use; emerging Windows magnification workflow; staff report of slower navigation with unfamiliar documents.

**Unknown:** Which steps take time; document structure; keyboard navigation; magnification settings; file format; learner perspective; tool compatibility.

**Practice task:** Select one digital task, create a task analysis, and measure accuracy, independence, and time without treating speed as the only outcome.

**Review:** Evaluate tools against actual task requirements, access preferences, compatibility, training, and district support. Device ownership does not establish proficiency.

## Case C: Orientation and mobility

A fictional learner practices a familiar route within a school building with an O&M professional. Staff want a consistent record of route components across practice sessions.

**Known:** The learner receives O&M instruction; the team wants consistent documentation for a selected route task.

**Unknown:** Which route and conditions are appropriate; target components; environmental changes; safety and problem-solving measures; learner priorities.

**Practice task:** Draft observable data fields from a fictional route description. Do not enter real route or location details into an unapproved tool.

**Review:** O&M instruction and safety decisions remain with qualified professionals and the learner. A checklist does not replace contextual judgment or assessment.

## Case D: Self-determination and access advocacy

A fictional high-school learner wants to participate more independently in planning accessible materials. Staff have observed occasions when the learner waited for an adult to notice an access problem.

**Known:** The learner wants greater involvement; staff observed occasions when an access issue was not raised.

**Unknown:** Whether the learner knows whom to contact; whether formats arrive on time; comfort requesting changes; accessibility of request methods; learner's preferred advocacy outcome.

**Practice task:** Design a student-led routine for one realistic access request. Measure identifying the need, choosing a communication method, making the request, and evaluating the result.

**Review:** Do not frame a system failure as a student deficit. Ensure materials and accommodations are available. Self-advocacy complements, not replaces, adult responsibility.

## Case analysis prompt

For any case, ask the model to return facts, unknowns, hypotheses, questions for the learner and team, possible environmental variables, and evidence needed before selecting an instructional target. Explicitly prohibit inference from diagnosis, acuity, grades, or device ownership.
