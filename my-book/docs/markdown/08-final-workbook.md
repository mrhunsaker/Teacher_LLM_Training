## Participant use

- Select one role-relevant fictional case and use the workbook progressively across the Plan → Refine → Build → Refine cycle.
- Complete professional planning sections before asking an LLM for assistance; work one bounded task at a time.
- Treat model output as a draft. Record corrections, rejected suggestions, evidence, student feedback, and professional decisions.
- Keep assessment, eligibility, IEP, service, placement, and safety decisions with qualified professionals and authorized teams.

## Source and privacy

The DOCX is generated from a Markdown source maintained in the repository for course-authoring and regeneration. Participants should use the DOCX rather than the source Markdown. Use fictional or district-approved information only, and do not enter identifiable student or staff information into an unapproved system.
